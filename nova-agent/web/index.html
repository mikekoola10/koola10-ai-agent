Scheduled

Daily report email + connector self-check
Daily report: Nova builds a text summary (connector health + task stats) and POSTs it to your webhook — a Zapier Catch Hook Zap that emails it to you. Configure via NOVA_DAILY_REPORT (1/0), NOVA_DAILY_REPORT_TIME (default 09:00), and NOVA_REPORT_PROVIDER (zapier|make|n8n). “Send report now” fires it immediately so you can test the email.

Credential Vault

Encrypted API keys & webhook URLs
What is this? Nova's encrypted vault stores API keys and webhook URLs (AES-256-GCM at rest). Entries stored under connector names — like ZAPIER_WEBHOOK_URL, N8N_WEBHOOK_URL, MAKE_WEBHOOK_URL, COMPOSIO_API_KEY — are picked up by Nova automatically when the env var isn't set, so you can connect things straight from the vault. Nova's agent can also read/write it with its vault tool. Values never leave the server.

Bounty Board

Human-review decks from the automated sweep
How this works: Nova sweeps 28 repos twice a day (07:40 & 19:40 ET) and drafts a review deck — ranked bounties, solution approach, and a ready-to-post first comment for each. Nova never posts anything. You review the deck here, edit if you like, then approve — that's the human-in-the-loop that keeps submissions clean.
