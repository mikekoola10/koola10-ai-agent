The loop

How a Nova run works

  1. 1

    Plan

    Nova breaks your request into a clear sequence of steps and decides which tools it needs.

  2. 2

    Act

    It executes each step with real tools — running commands, editing files, searching the web, calling APIs.

  3. 3

    Observe

    It reads the actual results, corrects course when something fails, and keeps moving.

  4. 4

    Report

    It writes long deliverables to files and delivers a concise final report of what was done.

FAQ

Questions, answered

Does Nova need a paid model key?

No. Nova can run in mock mode for local verification, and it ships with a free Hugging Face Inference route for open models when no paid provider key is set.

Where do my API keys live?

Server-side only, in your environment or encrypted vault. Nova never exposes keys to the browser or client bundles.

Is Nova safe to leave running?

Nova only triggers side-effecting actions (payments, messages, workflow runs) when you explicitly request them, and it reports provider errors without crashing.

How do I verify my connectors work?

Run node dist/index.js --verify-connectors to send a harmless ping to each configured provider and get a live status report.
